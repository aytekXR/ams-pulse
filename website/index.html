FAQ

Questions operators actually ask.

Does Pulse modify my Ant Media Server?

No. Pulse is read-only. It polls the AMS REST v2 API on a configurable interval (default 5 seconds) and never writes to AMS, never changes AMS configuration, and never touches the AMS filesystem or database. It survives AMS upgrades without any coordination.

Does my data leave my infrastructure?

No. Pulse is entirely self-hosted. There is no SaaS component and no phone-home. License verification is offline — keys are validated locally via an ed25519 signature check. Viewer IPs from the beacon SDK are SHA-256 hashed before storage.

What does installation involve?

Docker Compose or Helm. One Go binary plus ClickHouse, configured with a handful of environment variables. The acceptance criterion: install to first live dashboard in under 15 minutes.

We already run Prometheus and Grafana. Why Pulse?

Keep them — Pulse ships a /metrics endpoint. Grafana measures your servers; Pulse measures your audience: who is watching, on what device, with what startup time and rebuffer ratio, deduplicated across origin and edge nodes.

What happens when my license expires?

Pulse degrades gracefully to Free tier. The server keeps running; you can still read all already-collected data. Tier-gated features return 403 LICENSE_REQUIRED. A banner appears in the UI indicating the license state. Nothing crashes.

Where do viewer QoE numbers come from?

Viewer-side QoE metrics (startup time, stall/rebuffer ratio, bitrate, error rate) come from the Pulse Beacon JS SDK embedded in your player. The SDK posts events to your Pulse instance. No data is sent to any third party.

Does the player beacon slow down my player?

The SDK is 3.52 KB gzipped with a hard 15 KB budget, MIT-licensed and white-labelable. It batches events and posts to a rate-limited, token-authenticated ingest endpoint that is isolated from the admin API.

GDPR / KVKK — can we anonymize viewers?

Yes. Set PULSE_ANONYMIZE_IP=true and IPs are anonymized before geo lookup and storage; geo resolution degrades gracefully to country level. Data retention windows are configurable (90-day raw, 13-month rollups by default).

HONEST DISCLOSURE

What Pulse does not do (yet).

Pulse exists to tell you the truth about your streams. That commitment starts here: these are the current limitations you should know before deploying.

HLS viewer counts are approximate

hlsViewerCount from AMS is a sliding segment-request window, not a session count. With 5 real HLS viewers, Pulse may show 45. This is AMS platform behavior, not a Pulse defect. LIM-02

FPS reads 0 from AMS REST

currentFPS is absent from AMS 3.x BroadcastDTO. The health score redistributes the FPS weight so healthy streams still score above 80. LIM-04

Geo analytics need a MaxMind database

Country-level geo analytics require GeoLite2-City.mmdb, which is not bundled (MaxMind licensing). Mount the file and set PULSE_GEO_MMDB_PATH. Without it, country fields are blank. LIM-05

Cluster edge/origin dedup is inactive

AMS 2.14 through 3.x exposes no node role field. All nodes display as origin, and edge/origin viewer deduplication never activates. This is provable from the AMS wire shape. LIM-10

Kafka path is experimental

The Kafka consumer is code-complete and fixture-tested, but has never connected to a real AMS Kafka producer. Topic names are source-derived. Treat this path as preview until live-validated. LIM-19

Interactive PDF export is not implemented

On-demand format=pdf returns 501. Scheduled PDF reports (Business+) work. Use CSV export or browser Print for one-off PDFs. LIM-24
