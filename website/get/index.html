Get Pulse

Install Pulse next to your Ant Media Server in a few minutes. Every feature is free for any use, including commercial use.

STEP 1

Check what Pulse needs

  • A Linux host with Docker Engine 24+ and Docker Compose v2, 2 vCPU and 2 GB RAM.
  • Network access from that host to your Ant Media Server REST API (normally port 5080).
  • An AMS admin login for Pulse — a dedicated account is best.
  • In each AMS application Pulse should monitor, the Pulse host's IP added to the application's REST IP filter (AMS allows only 127.0.0.1 by default).

Pulse installs nothing on Ant Media Server — no plugin, no restart. It only reads the REST API.

STEP 2

Run the installer

$ curl -fsSL https://raw.githubusercontent.com/aytekXR/ams-pulse/main/deploy/quickstart/install.sh \
    | bash -s -- --ams-url http://YOUR-AMS:5080 \
                 --email YOUR-AMS-ADMIN-EMAIL \
                 --password 'YOUR-AMS-PASSWORD'

All three flags are required when the script is piped into bash. The installer pulls the signed Pulse image, starts Pulse and ClickHouse, checks that Pulse can reach your AMS, and prints a one-time admin token. Prefer to read it first? View install.sh.

Kubernetes, offline hosts and production hardening: install guide.

STEP 3

Open the dashboard

Go to http://<your-server>:8090 and sign in with the admin token the installer printed. Your streams appear within seconds; the green Live badge means updates are streaming in.

Port 8090 serves plain HTTP. On a public server, put a TLS reverse proxy in front of it and use https://pulse.your-domain.

OPTIONAL

Verify the image signature

Images are signed with Cosign and ship with an SBOM and SLSA provenance. Use Cosign v3 or newer (v2 cannot read the OCI 1.1 signature format and reports "no signatures found"). 

$ cosign verify \
    --certificate-identity-regexp '^https://github\.com/aytekXR/ams-pulse/\.github/workflows/release\.yml@refs/tags/v.+$' \
    --certificate-oidc-issuer https://token.actions.githubusercontent.com \
    ghcr.io/aytekxr/ams-pulse:0.5.1

Stuck?

The most common first-install issue is the AMS REST IP filter (HTTP 403 in the Pulse logs).
