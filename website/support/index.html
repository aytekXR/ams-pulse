Support

Pulse is maintained by a single developer. Response times are honest, not aspirational.

GETTING HELP

Where to ask

GitHub Issues

The primary support channel for bugs, questions, and feature requests.

Open an Issue

Before opening a new issue, search existing issues to see if your question has already been answered.

Response expectations

This is a single-maintainer project. Issues are triaged regularly, but response times vary. Critical bugs and security issues receive priority. Feature requests are tracked but may take time to implement. Thank you for your patience.

BUG REPORTS

What to include

A good bug report helps resolve issues faster. Please include:

Pulse version

The version number from the UI footer or pulse version output.

AMS version

Your Ant Media Server version (e.g., 3.0.3 Enterprise).

Steps to reproduce

What you did, what you expected, what actually happened.

Logs

Relevant output from docker compose logs pulse or the binary stderr.

Environment

Docker Compose or Helm, host OS, and any relevant config (sanitize secrets).

Health check

Output of curl http://localhost:8090/healthz.

SECURITY

Reporting vulnerabilities

Please report security vulnerabilities by email. Do not open a public GitHub issue for security vulnerabilities.

Email: aytek@beyondkaira.com

Include a description of the issue, reproduction steps, and potential impact. You will receive a response within 5 business days.
